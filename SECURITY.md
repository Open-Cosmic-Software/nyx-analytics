# Security policy

## Supported versions

Security fixes go into the latest minor release. Please stay on the newest `2.x`.

## Reporting a vulnerability

Please report vulnerabilities **privately**:

- via GitHub: **Security → Report a vulnerability** on this repository, or
- by e-mail to **hello@tacilytics.com** (subject: `SECURITY`).

Include what you found, how to reproduce it and which version you tested. We aim to answer within 72 hours and to ship a fix for serious issues as a patch release.

Please give us a reasonable time to fix the issue before disclosing it publicly. Thank you for helping keep Tacilytics and its users safe.
